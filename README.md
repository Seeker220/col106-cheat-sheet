# COL106 Cheat Sheet

This is a comprehensive cheat sheet for the COL106 (Data Structures) course, designed for open-book tests.

## Document Structure

The cheat sheet is organized into 9 modules covering:

1. **Module 1**: Algorithm Analysis & Amortization
2. **Module 2**: Linear Data Structures (Lists, Stacks, Queues)
3. **Module 3**: Trees, Heaps, & Priority Queues
4. **Module 4**: Heap Applications & Greedy Algorithms
5. **Module 5**: Hash Tables
6. **Module 6**: Search Trees (BST, AVL, B-Trees)
7. **Module 7**: Graph Algorithms
8. **Module 8 (Part 1)**: Problems (Pre-BST & DP)
9. **Module 8 (Part 2)**: Problems (Post-BST)
10. **Module 9**: Exercise & Challenge Solutions

## Building the PDF

To build the PDF from the LaTeX source:

```bash
pdflatex main.tex
```

You may need to run it twice to properly generate the table of contents.

None found during the numbering process. All content has been preserved exactly as it was.
